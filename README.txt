تشغيل الصفحة على Mac (يوصى بسيرفر محلي)
1) افتح Terminal داخل مجلد المشروع
2) شغّل:
   python3 -m http.server 8080
3) افتح المتصفح على:
   http://localhost:8080

الاستخدام:
- زر "تحميل بيانات العينة" يعرض data.sample.json
- أو ارفع ملف CSV/JSON بنفس أعمدة ملفك (م/اسم الدار/التغطية/هدف المحفظة/المراحل/1..30)
- الصفحة تنظف الأرقام تلقائيًا وتعرض:
  - ملخص إجمالي
  - قائمة قابلة للبحث والترتيب
  - تفاصيل + مراحل + خطة 30 يوم
